# rec/ — video explicativo

Este directorio contiene el video asciinema de **Jarvis CAN: telemetría OBD-II sin nube** y el reproductor
que se usa en la página del proyecto.

- `jarvis-can.cast`: grabación original (asciicast v2).
- `jarvis-can.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:32. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
